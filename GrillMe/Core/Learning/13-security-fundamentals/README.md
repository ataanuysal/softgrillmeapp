## Bu modül ne yapacak

Yaygın saldırı sınıflarını ve savunmanın nereden başladığını; kimlik doğrulama ile yetkilendirmeyi anlatır.

## Öğrenme hedefleri

- Kimlik doğrulama ile yetkilendirmeyi ayırmak
- Girdi doğrulamayı savunmanın ilk katmanı yapmak
- Parola ve gizli veri saklamanın kurallarını uygulamak
- Yaygın açık sınıflarını tanımak

## Planlanan dersler

1. Tehdit modeli
2. Kimlik doğrulama
3. Yetkilendirme
4. Girdi doğrulama
5. Şifreleme temelleri
6. Gizli veri yönetimi
