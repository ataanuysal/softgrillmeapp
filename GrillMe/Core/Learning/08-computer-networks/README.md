## Bu modül ne yapacak

İki makinenin nasıl konuştuğunu; katmanları, protokolleri ve gecikmenin kaynağını anlatır.

## Öğrenme hedefleri

- Katmanlı ağ modelini açıklamak
- TCP ile UDP arasındaki farkı gerekçelendirmek
- Bir HTTP isteğinin yolculuğunu izlemek
- Gecikme ve bant genişliğini ayırmak

## Planlanan dersler

1. Katmanlı model
2. IP ve yönlendirme
3. TCP ve UDP
4. DNS
5. HTTP
6. TLS temelleri
