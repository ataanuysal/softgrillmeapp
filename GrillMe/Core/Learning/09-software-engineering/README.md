## Bu modül ne yapacak

Kod yazmanın etrafındaki işi: sürüm kontrolü, gözden geçirme, iş akışı ve teknik borç.

- Sürüm kontrolünü günlük iş akışında kullanmak
- Anlamlı commit ve gözden geçirme yazmak
- Gereksinimi çalışılabilir işe bölmek
- Teknik borcu görünür kılmak
